Mall Customers Dataset

This document explains the basic cleaning and validation steps performed on the Mall Customers dataset.

Steps:
Created a table for the full dataset for easy viewing and analysis
Adjusted column size (auto-fit) for better readability
Checked the Gender column using filters and confirmed only valid values (Male and Female) are present
Verified there are no duplicate records
Checked for missing values and confirmed there are no blank entries
Reviewed column names and corrected formatting issues:
Annual Income (k$) changed to Annual_Income (k$)
Spending Score (1-100) changed to Spending_Score (1-100)
Checked and confirmed correct data types for all columns
Verified Age values are valid (range: 18 to 70)
No major outliers found in the dataset
Confirmed all Customer IDs are unique
Checked value ranges:
Annual Income: $15 to $137
Spending Score: 1 to 100 (valid range)
Conclusion

The dataset is clean and consistent.
